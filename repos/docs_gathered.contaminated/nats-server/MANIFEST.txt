00_README.md — Project Overview and Documentation Index: NATS Server is a Go-based pub/sub + request/reply + JetStream messaging system; this file introduces the codebase, key terminology (subject, account, user, stream, consumer, $JS.API.*, FilterSubject vs FilterSubjects), and indexes the audit-input file set.
01_security_model.md — NATS Security Model: subject-based publish/subscribe ACLs with deny-precedes-allow semantics, the $JS.API.* API surface governed by the same core ACLs, account isolation as the multi-tenancy boundary, and the system account $SYS as the privileged cluster-wide trust boundary.
02_jetstream_api_contract.md — JetStream API Contract: the jsConsumerCreateRequest decoding into addConsumerWithAction, what is and is not checked (config validity, stream-subject overlap, and API-subject publish permission — but NOT the caller's subscribe ACL against FilterSubject/FilterSubjects), and the asymmetry between the singular and plural filter fields.
03_authorization_boundaries.md — Authorization Boundaries: the two surfaces (core subject ACL vs $JS.API.* ACL) have different units and overlap imperfectly; the maintainer-documented mitigation via the extended consumer-create subject `$JS.API.CONSUMER.CREATE.<stream>.<consumer>.<filter>` works for filter_subject only, and #6180 documents the residual filter_subjects gap.
04_invariants.md — Authorization Invariants in "must always / must never" form, organized by cluster (consumer subscribe ACL, ACL precedence, account isolation, system-account scoping, identity propagation, pre-auth resource bounds, file/path integrity), each citing the doc passage or CVE that establishes it.
05_known_issues_and_advisories.md — Known Issues and Security Advisories: full text of the #4225 maintainer acknowledgment and #6180 residual-gap description, plus the relevant CVEs (CVE-2025-30215 cross-account purge, CVE-2026-33222 restore-bypass, CVE-2022-29946 deny-queue-leak, CVE-2022-24450 account assumption, CVE-2021-3127 import-token replay, and the related identity/MQTT/DoS clusters).
06_issue_tracker_themes.md — Six recurring themes drawn from the issue tracker: (1) JetStream consumer reads escape subscribe ACLs (the NATS-1 family — #3202/#4225/#6180), (2) wildcard evaluation inconsistency across boundaries (#4832, #6016), (3) JetStream/leaf-node/JWT interactions (#6293, #3819), (4) account isolation in JetStream ingest (#3108), (5) recurring operator misconfigurations, (6) pre-authentication resource safety.
