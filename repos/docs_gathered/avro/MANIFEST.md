# Manifest — Apache Avro reference corpus

- `overview.md` — What Avro is, its design philosophy, and what an Avro implementation provides.
- `schema_model.md` — Schema declaration, primitive and complex types, naming and aliases, Avro IDL.
- `binary_and_json_encoding.md` — Binary wire format for primitives and complex types, JSON encoding, single-object framing.
- `object_container_files.md` — Container file layout, metadata, codecs, reader/writer APIs.
- `schema_resolution.md` — Reader/writer schema matching rules, parsing canonical form, fingerprints, compatibility utilities.
- `rpc_protocols.md` — Protocol declarations, framing, handshakes, transports, and the SASL profile.
- `language_implementations.md` — Source layout of the Java, Python, C++, and C# implementations.
- `logical_types.md` — Decimal, UUID, date/time, timestamp, local-timestamp, and duration logical types.
