00_README.md — Gogs: Project Overview. Self-hosted Git service in Go (47.6K stars), Macaron web framework, single binary serving Web UI + REST API + Git transport, key terminology (user / org / team / repo / collaborator / access mode / deploy key / PAT / protected branch / LFS), high-level architecture, and why broken-access-control is the dominant defect class.
01_security_model.md — Gogs Security Model: Roles, Trust Boundaries, and Access Modes. The 5-level access-mode ladder (None/Read/Write/Admin/Owner) and the 8-role hierarchy (site admin → org owner → team admin → repo admin/writer/reader → authenticated non-collaborator → anonymous), public vs private vs partially-public repos, org-team semantics, every trust boundary in the system, and the documented non-guarantees (no PAT scopes, no row-level DB filtering, no CSRF on the API).
02_api_and_endpoint_contract.md — Gogs API and Web-UI Endpoint Contract. The Macaron route-declaration model, the full middleware vocabulary (reqSignIn, reqRepoWriter, reqRepoAdmin, RepoAssignment, GitHookService, etc.) with exact fail behavior, the "middleware authorizes URL repo, handler must authorize target object" pattern, REST API authentication paths, and the web-UI/API parity-gap pattern that produced CVE-2026-25229.
03_access_control_patterns.md — Gogs Access-Control Patterns and Footguns. Canonical safe shapes (scoped DB helpers, post-load repo-binding check, ownership-or-admin guard) and the four broken-access-control shapes that recur in the codebase (no gate / wrong tier / unscoped load with role check on URL repo / web-UI vs API divergence), each anchored to the CVE that proved it real.
04_invariants.md — Gogs Authorization Invariants. "X must always / X must never" statements grouped by concern (authentication, broken access control = the CASE-010 core, cross-tenant isolation, site-admin operations, repo settings, object creation, path handling, webhooks), each tagged to the CVE/GHSA that validates it. Includes documented non-invariants.
05_known_issues_and_advisories.md — Gogs Known Issues and Advisories. The CASE-010 candidate set in detail (CVE-2026-25229 label authz bypass as the primary candidate, plus CVE-2026-25120, CVE-2026-25232, CVE-2026-23632, CVE-2025-65852, CVE-2026-25921, CVE-2026-25242), non-BAC advisory clusters (path traversal, command injection, auth weaknesses, XSS, DoS), the fix-pattern summary for blind detection, and notes on the security-policy mechanics.
06_issue_tracker_themes.md — Gogs Issue Tracker Themes. Six recurring concerns from the public tracker: permission-model confusion, protected-branch enforcement gaps, webhook firing semantics, web-UI vs API divergence, org-team edge cases, and partial-public anonymous exposure. Includes the counterpoint that BAC bugs are reported through the private advisory workflow, not the public tracker.
