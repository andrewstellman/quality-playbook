Behavioral contracts extracted from the harness/gate/registry code (Tier 3 — code is the authority). Each maps to one or more REQs.

## Detached collector (`bin/harness/plan_runner.py`)

- **C-01** — `collect_harness_run` reads `manifest.json`, runs `_retry_pending_runs_once` once, then submits `_collect_one_run_detached` for every entry in `manifest["runs"]` (`:2606-2611`). → REQ-001 (no state filter is the defect surface).
- **C-02** — `_collect_one_run_detached` short-circuits when `grading.json` exists, reconstructing the outcome from `grading.json`+`facts.json` (`:2015-2052`); a `json.JSONDecodeError`/`KeyError` on `grading.json` falls through to re-collect, but `facts.json` inconsistency does not. → REQ-007.
- **C-03** — The orphan-poll loop classifies terminal state from the stream (`_classify_stream_terminal`), then from PID liveness + artifacts; `pid is None` enters the "process gone" branch → `FAILED` when no gate-report/quality dir exists (`:2123-2146`). → REQ-001.
- **C-04** — `_write_terminal_status` returns early without writing when the on-disk `status.json` already has a truthy `terminal_state` (`:2306-2312`). → REQ-008.
- **C-05** — `_launch_one_run_detached` returns a manifest-entry dict with `index`, `pid`, `started_at`, `run_dir`, … but **no `state` key** (`:1844-1872`). → REQ-003.
- **C-06** — `_retry_pending_runs_once` acquires a slot (`:2509`), relaunches (`:2530`), and merges the returned dict into the manifest (`:2538`) — without calling `update_pid`. → REQ-002, REQ-003.
- **C-07** — A PENDING entry past `_pending_deadline_s()` (default 3600s) is marked `ABANDONED_STARVED` (`:2488-2499`); the deadline is measured from `starved_since`, set on the first acquire timeout (`:2521-2526`). → REQ-001.

## Per-provider concurrency registry (`bin/harness/inflight_registry.py`)

- **C-08** — `acquire_run_slot` reserves a `pid=0` placeholder under the registry lock once both the per-provider cap (`max_per_provider.get(provider, 1)`) and the optional `plan_pool_cap` have capacity (`:448-470`). → REQ-006.
- **C-09** — `update_pid` converts a `pid=0` reservation to the real PID; the only call site is the orchestrator launch path (`plan_runner.py:3078`). → REQ-002.
- **C-10** — `_entry_is_active`: a `pid=0` entry is active iff younger than `_pid_zero_max_age_s()` (default 300s); a missing/unparseable `started_at` returns `True` (active, never reaped) (`:341-348`). → REQ-005.
- **C-11** — `read_active_runs` prunes dead-pid entries and writes the pruned list back when `prune_dead=True` (`:377-396`). → REQ-006.
- **C-12** — `release_run_slot` is idempotent (no-op when no matching entry); called at every terminal return path of `_collect_one_run_detached`. → REQ-006.

## Run status reporting (`bin/harness/status.py`)

- **C-13** — `_infer_phase_from_artifacts` returns the highest-numbered phase in `_PHASE_ARTIFACTS` with at least one artifact present under `<target>/quality/` (`:358-401`). → REQ-004.
- **C-14** — `_PHASE_ARTIFACTS` maps P1→EXPLORATION.md, P2→{REQUIREMENTS,CONTRACTS,COVERAGE_MATRIX}, P3→{RUN_CODE_REVIEW,BUGS}, P4→COMPLETENESS_REPORT, P5→QUALITY, P6→results/gate-report-latest.json (`:285-316`). The P4/P5 entries contradict the runner's Phase-2 prerequisite list. → REQ-004.

## Install validation (`bin/qpb_validate.py`)

- **C-15** — `check_stale_quality_dir` flags a `quality/` containing files (excluding dotfiles + `RUN_INDEX.md`) without a `run_state.jsonl` carrying a `run_start` within 24h (`:1272-1324`). → REQ-009.
- **C-16** — Multiple AI-tool markers without `--ai-tool` → `status=blocked` with a `select_ai_tool` remediation. → REQ-009.

## Council roster (`bin/council_config.py`)

- **C-17** — `council_members()` returns the operator's `council_members` config when it is a non-empty list of non-empty strings (after `validate_roster` warnings), else `DEFAULT_COUNCIL_MEMBERS`; any import/parse/shape failure falls back to defaults without crashing (`:47-110`). It does **not** enforce roster size 3. → REQ-010.

## Run archival (`bin/archive_lib.py`)

- **C-18** — `archive_run` raises `ArchiveError` if `quality/previous_runs/<run_id>/` already exists (`:821-826`); `run_id = timestamp + STATUS_SUFFIX[status]`, timestamp at 1-second resolution. → REQ-011.
- **C-19** — `copytree` excludes `previous_runs`/`runs` so a fresh archive doesn't recursively include prior archives. → REQ-011.

## Source-edit guard (`bin/run_state_lib.py`)

- **C-20** — `validate_no_source_edits` runs `git status --porcelain -z`, parsing each entry as `status path` and skipping the source field of `R`/`C` renames (destination-first, verified); any path outside `allowed_prefixes` (default `("quality/",)`) is a violation (`:976-1095`). Silent pass when git is missing or `target_dir` is not a repo. → REQ-012.
