### BUG-001
- **Severity:** HIGH · **Requirement:** REQ-001 · **Disposition:** code-fix (fix_type: code)
- **File:** `bin/harness/plan_runner.py:2606-2611` (submit loop) + `:2123-2146` (`_collect_one_run_detached` orphan-poll)
- **Description:** `collect_harness_run` submits `_collect_one_run_detached` for *every* manifest entry with no state filter. A starved entry with `state="PENDING"` and `pid=None` falls into the "process gone" branch (`pid is None`) and is graded `FAILED`, even though it simply hasn't acquired a provider slot yet — defeating the 3600s `ABANDONED_STARVED` deadline (instruction 165) that exists to give it time across later collector passes.
- **Reproduction:** build a manifest entry `{state:"PENDING", pid:None, max_duration_s:3600}` with no stream file; call `PR._collect_one_run_detached(entry, harness_dir)`. **Expected:** not graded terminal (left PENDING). **Actual:** `terminal_state == "FAILED"`. `test_bug_001` xfails.
- **Spec basis:** Tier-3 — `CONTRACTS.md` C-01/C-03/C-07 + REQ-001; the run-state machine's PENDING semantics and the 165 deadline.
- **Regression test:** `quality/patches/BUG-001-regression-test.patch` → `test_bug_001_pending_pidless_not_graded_failed`. **Fix:** `quality/patches/BUG-001-fix.patch`.

### BUG-002
- **Severity:** HIGH · **Requirement:** REQ-002 · **Disposition:** code-fix (fix_type: code)
- **File:** `bin/harness/plan_runner.py:2509-2545` (`_retry_pending_runs_once`) vs the compliant orchestrator path `:3078`
- **Description:** The collector retry path acquires a `pid=0` slot reservation and spawns the run but never calls `update_pid`, so the reservation stays at `pid=0` and ages out after `_PID_ZERO_MAX_AGE_S = 300s` (`inflight_registry.py:341-348`). - **Spec basis:** Tier-3 — `CONTRACTS.md` C-06/C-09; the orchestrator path at `:3078` is the authoritative pattern.
- **Regression test:** `quality/patches/BUG-002-regression-test.patch` → `test_bug_002_retry_launch_calls_update_pid`. **Fix:** `quality/patches/BUG-002-fix.patch`.

### BUG-005
- **Severity:** MEDIUM · **Requirement:** REQ-005 · **Disposition:** code-fix (fix_type: code)
- **File:** `bin/harness/inflight_registry.py:343-345` (`_entry_is_active`)
- **Description:** A `pid=0` reservation whose `started_at` fails to parse returns active *forever* (`if started is None: return True`) — a permanent phantom slot that reduces the per-provider cap by one indefinitely. The current spawn paths write a valid `started_at`, so this is a latent risk (hence MEDIUM), but the invariant "every `pid=0` reservation carries a parseable `started_at`" is unenforced.
- **Reproduction:** `IR._entry_is_active({"pid":0,"started_at":"not-a-date"})`. **Expected:** False (stale). **Actual:** True. `test_bug_005` xfails.
- **Spec basis:** Tier-3 — `CONTRACTS.md` C-10; REQ-005.
- **Regression test:** `quality/patches/BUG-005-regression-test.patch` → `test_bug_005_pid0_malformed_started_at_not_active_forever`.
- **Fix:** no separate `.patch` — the conservative fix is provided as an inline diff in `quality/writeups/BUG-005.md`. **Justification for deferral:** the current `return True` is a documented intentional choice ("never mass-reap on a parse failure", `inflight_registry.py:339-340`); flipping it to age-out trades the phantom-slot risk for a mass-reap-on-transient-glitch risk, so the apply decision is left to the maintainer. Remains `confirmed open (xfail)`.

### BUG-006

- **Description:** The greedy regex `\[[\s\S]*\]` matches first-`[` to last-`]`, contradicting the docstring's "first balanced block / outermost that parses." - **Spec basis:** Tier-3 — the function's own docstring + REQ-010 (Layer-2 majority must stay well-defined).
