# BUG-007 — capture_phase_yn reports P3–P6 complete from Phase-2 artifacts

> Generated by [Quality Playbook](https://github.com/andrewstellman/quality-playbook) v1.5.7 — Andrew Stellman
> Date: 2026-05-30 · Project: quality-playbook

## 1. Summary
`capture_phase_yn` (`bin/harness/plan_runner.py:582-610`) decides each phase's Y/N from the transcript OR an artifact-presence fallback. The fallback maps P3→`RUN_CODE_REVIEW.md`, P4→`RUN_SPEC_AUDIT.md`, P5→`RUN_TDD_TESTS.md`, P6→`COMPLETENESS_REPORT.md` — but **all four are Phase-2 Generate outputs**, so a run that only reached Phase 2 is marked as having completed P3–P6 in the SUMMARY phase grid.

## 2. Spec reference
Tier-3. REQ-004 generalized ("a phase is Y only if it actually ran; key on a phase-exclusive marker") + the SKILL artifact contract (RUN_*.md and COMPLETENESS_REPORT.md are Phase-2 deliverables).

## 3. The code
The artifact map at `:599-606` uses Phase-2 filenames for P3–P6. The non-COMPLETED cleanup at `:2240-2243` only flips `N`→`-`; it never demotes a false `Y`. So a wedged-after-Generate run keeps P3–P6 = Y.

## 4. Observable consequence
A run that hangs in Phase 3 (the longest phase) but already wrote the Phase-2 protocol files shows `P3 P4 P5 P6 = Y Y Y Y` in `SUMMARY.md` and `RunOutcome.phase_yn` — the operator's benchmark summary reports a wedged run as fully complete. Same root cause as BUG-004 but in the grading/summary path rather than the live status display.

## 5. Depth judgment
Masked on COMPLETED runs (the transcript signals every phase, so the artifact fallback is moot) and on verbose Mode-A transcripts. Bites terse/Mode-B transcripts of non-COMPLETED runs — precisely the runs an operator most needs an accurate phase grid for.

## 6. The fix
```diff
--- a/bin/harness/plan_runner.py
+++ b/bin/harness/plan_runner.py
@@ capture_phase_yn artifact map
-                "P3": "RUN_CODE_REVIEW.md",
-                "P4": "RUN_SPEC_AUDIT.md",
-                "P5": "RUN_TDD_TESTS.md",
-                "P6": "COMPLETENESS_REPORT.md",
+                "P3": "BUGS.md",
+                "P4": None,
+                "P5": "results/tdd-results.json",
+                "P6": "results/gate-report-latest.json",
```
Full patch: `quality/patches/BUG-007-fix.patch` (applies cleanly; TDD-verified). P4 has no fixed-path single-file marker (the triage is `spec_audits/<date>-triage.md`, glob-only), so it falls back to the transcript signal only — under-report beats false-complete.

## 7. The test
`test_bug_007_capture_phase_yn_no_false_completion` builds a Phase-2-only `quality/` with an empty transcript and asserts no P3–P6 is `Y`. Unpatched: FAIL (all four Y; `BUG-007.red.log`). Patched: PASS (`BUG-007.green.log`).
