## Summary
bootstrap_self_audit_docs.main() creates `reference_docs/cite/` but never copies source-side cite files into it.

## Spec reference
- Requirement: REQ-004
- Spec basis: `quality/REQUIREMENTS.md:53-64`
- Behavioral contract quote: "mirror both top-level context docs and `cite/` formal docs"

## The code
At `bin/bootstrap_self_audit_docs.py:50-61` At `bin/bootstrap_self_audit_docs.py:50-61`, the helper creates `reference_docs/cite/` and then iterates only the top level of `docs_gathered/`. Subdirectories are skipped entirely, so `docs_gathered/cite/spec.md` is never mirrored even though the destination cite directory is created.

## Observable consequence
When a maintainer bootstraps self-audit docs from a source tree containing both top-level notes and `docs_gathered/cite/spec.md`, the contextual note is copied but the citable spec is silently dropped. The resulting `reference_docs/` tree loses the formal-doc evidence bucket that later phases are supposed to read.

## The fix
The fix keeps the top-level mirroring loop and adds a second, explicit pass for `docs_gathered/cite/`, preserving the source-side placement contract.
