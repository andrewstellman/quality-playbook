For each confirmed bug in `quality/BUGS.md`, prove the regression test fails on unpatched code (RED) and passes after the fix patch (GREEN).

## Runner probe (mandatory, first)

Probe before any verdict and capture to `quality/results/phase5_env.log`:

```bash
{ echo "=== python ==="; python3 --version; echo "=== real pytest ==="; \
  (cd /tmp && python3 -c "import pytest; print(pytest.__version__, pytest.__file__)"); } \
  > quality/results/phase5_env.log 2>&1; echo "exit=$?" >> quality/results/phase5_env.log
```

Real pytest 8.x is installed at the user site-packages. **The repo's local `pytest/` shim shadows it when cwd is the repo root** — so TDD test runs MUST use real pytest: run from a scratch dir with the absolute path, `(cd /tmp && python3 -m pytest <repo>/quality/test_regression.py::<test> -v)`, or invoke the `pytest` console script. A probe success means you MUST execute the tests for real — a `RED`/`GREEN` first-line tag over a by-inspection body fails the gate (089o).

## Per-bug red/green sequence

Regression tests are pytest `xfail(strict=True)`. The red/green phases temporarily bypass the guard:

```bash
# RED — bug present, test must fail (xfail→ assertion fires when guard removed)
git apply -R quality/patches/BUG-NNN-fix.patch 2>/dev/null   # revert fix if applied
TEST="(cd /tmp && python3 -m pytest /Users/andrewstellman/Documents/QPB/quality/test_regression.py::test_bug_nnn -rA -q --runxfail)"
OUT=$(eval "$TEST" 2>&1); EXIT=$?
printf 'RED\n--- BUG-NNN red ---\nCommand: %s\nExit code: %d\n%s\n' "$TEST" "$EXIT" "$OUT" > quality/results/BUG-NNN.red.log

# GREEN — apply fix, same test must pass
git apply quality/patches/BUG-NNN-fix.patch
OUT=$(eval "$TEST" 2>&1); EXIT=$?
printf 'GREEN\n--- BUG-NNN green ---\nCommand: %s\nExit code: %d\n%s\n' "$TEST" "$EXIT" "$OUT" > quality/results/BUG-NNN.green.log
git apply -R quality/patches/BUG-NNN-fix.patch   # revert — no source left dirty at run end
```

`--runxfail` makes the xfail-marked test report its real pass/fail so RED (fail) vs GREEN (pass) is visible. First line of each log MUST be `RED`/`GREEN`/`NOT_RUN`/`ERROR`.
