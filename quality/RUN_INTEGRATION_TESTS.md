## Recording results

Write the Phase 4 execution results to `quality/results/integration-results.json` with schema version `1.1`.

Use this root shape:

```json
{
  "schema_version": "1.1",
  "skill_version": "1.5.6",
  "date": "2026-05-08",
  "project": "QPB",
  "recommendation": "pass | investigate | fail",
  "groups": [],
  "summary": {},
  "uc_coverage": {}
}
```

Each executed group should record:

- command
- mapped REQs
- mapped UCs
- pass/fail status
- failing test names
- concise notes on any mismatches

## Exit criteria

- Every group has been executed or explicitly marked `NOT_RUN`.
- Any failure is traced back to one or more REQs.
- `uc_coverage` includes `UC-01` through `UC-08`.
- No result claims "pass" while the mapped tests actually fail.
