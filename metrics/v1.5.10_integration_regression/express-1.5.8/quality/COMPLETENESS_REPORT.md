## Test count

`quality/test_functional.js` contains 8 fitness-scenario tests (some with per-UC sub-tests, ~12
test cases), 6 spec-requirement tests, and 6 boundary/edge tests — ~24 meaningful tests, each
importing and calling real Express code via `require('..')` + supertest. Lower than the 35–50
medium-project heuristic because the audited surface is concentrated (6 source files, behavior
delegated heavily to dependencies) and routing is out of scope; every test exercises a real
behavioral property — none are padding.
