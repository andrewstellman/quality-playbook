**Scope.** Contracts extracted from chi's core router (`mux.go`, `tree.go`, `context.go`,
`chain.go`, `chi.go`) plus the highest-risk middleware surfaced in Phase 1
(`middleware/compress.go`, `middleware/realip.go`, `middleware/content_charset.go`,

`middleware/content_type.go`). The ~30 other middleware are out of scope for this pass; the
six FULL-pattern seams from EXPLORATION.md drive contract selection. Contracts are
*observable behaviors the code commits to*, not implementation notes.

### mux.go (8 contracts)

- **C-MUX-1** — Under `Mount(prefix, sub)`, the dispatch closure shifts `rctx.RoutePath = mx.nextRoutePath(rctx)` so the sub-router sees the mount-*relative* path (`mux.go:309-322`). Covered by REQ-001, REQ-004.
- **C-MUX-2** — The mount dispatch closure zeroes the connecting `*` URLParam value after shifting (`mux.go:316-319`). Covered by REQ-004.
- **C-MUX-3** — `routeHTTP` reads `rctx.RoutePath` (the canonical mounted path) as the path to route on, falling back to `r.URL.Path` only when empty (`mux.go:441-456`). Covered by REQ-001.
- **C-MUX-4** — `routeHTTP` responds 405 when `RouteMethod` is absent from `methodMap` (`mux.go:462-466`). Covered by REQ-003.
- **C-MUX-5** — `methodNotAllowedHandler` builds the `Allow` header strictly from `reverseMethodMap` for the allowed-method set (`mux.go:518-526`). Covered by REQ-003.
- **C-MUX-6** — `Find` shifts `RoutePath` for mounted lookup (`mux.go:383`) but does NOT zero the `*` URLParam the live closure clears (C-MUX-2) — an observed divergence between lookup and live dispatch. Covered by REQ-004.
- **C-MUX-7** — `Match` is defined as `Find(...) != ""` and documents that the passed `*Context` is mutated during execution (`mux.go:353-368`). Covered by REQ-001 (live-context-mutation hazard), REQ-004.
- **C-MUX-8** — `nextRoutePath` reconstructs the child-relative path from the last `*` routeParam, defaulting to `/` (`mux.go:487-494`). Covered by REQ-001, REQ-004.

### tree.go (6 contracts)

- **C-TREE-1** — `methodMap`, `reverseMethodMap`, and `mALL` are three renderings of one closed method set that must stay in lock-step (`tree.go:32-57`). Covered by REQ-003.
- **C-TREE-2** — `RegisterMethod` updates all three structures together and guards bit width (`tree.go:61-77`). Covered by REQ-003.
- **C-TREE-3** — Wildcard registration fans an endpoint across every `methodMap` entry (`tree.go:355-365`). Covered by REQ-003.
- **C-TREE-4** — `findRoute` pushes a candidate param value and, on backtrack failure, truncates `routeParams.Values[:prevlen]` at two cleanup sites that must keep Keys/Values length-consistent (`tree.go:457-490`, `tree.go:534-539`). Covered by REQ-008.
- **C-TREE-5** — `FindRoute` appends `paramKeys` to `URLParams` assuming exact Keys↔Values correspondence (`tree.go:386-394`). Covered by REQ-008.
- **C-TREE-6** — `walk()` collapses `/*/`→`/` on full routes textually (`tree.go:862`). Covered by REQ-005.

### context.go (4 contracts)

- **C-CTX-1** — `RoutePattern()` joins `RoutePatterns` then `replaceWildcards` (`context.go:123-134`). Covered by REQ-005.
- **C-CTX-2** — `replaceWildcards` loops `strings.ReplaceAll(p, "/*/", "/")` until none remain — purely textual (`context.go:136-144`). Covered by REQ-005.
- **C-CTX-3** — `RoutePattern()` strips a single trailing `//` then a single trailing `/` in that order, unless the pattern is exactly `/` (`context.go:129-132`). Covered by REQ-005.
- **C-CTX-4** — `URLParam(key)` reads by reverse index, returning the last-pushed value for a key (`context.go:100-107`). Covered by REQ-008.

### middleware/compress.go (6 contracts)

- **C-CMP-1** — `selectEncoder` splits Accept-Encoding on `,` after lowercasing, with NO per-element trim and NO `;q=` parse (`compress.go:212-215`). Covered by REQ-002.
- **C-CMP-2** — `matchAcceptEncoding` returns true on the first `strings.Contains(v, encoding)` — substring, not token (`compress.go:240-246`). Covered by REQ-002, REQ-007.
- **C-CMP-3** — `defaultCompressibleContentTypes` is the closed eligibility set (`compress.go:16-27`). Covered by REQ-006.
- **C-CMP-4** — `isCompressible` checks exact membership after stripping `;`-params, then a configured wildcard set (`compress.go:274-288`). Covered by REQ-006.
- **C-CMP-5** — `WriteHeader` sets `Content-Encoding: <cw.encoding>` and deletes `Content-Length` only when compressible and an encoder was selected (`compress.go:298-316`). Covered by REQ-007.
- **C-CMP-6** — `writer()` returns the encoding writer iff `cw.compressible`, else the raw writer (`compress.go:326-331`). Covered by REQ-007.

### middleware/realip.go (2 contracts)

- **C-RIP-1** — `realIP` prefers True-Client-IP, then X-Real-IP, then the leftmost `,`-segment of X-Forwarded-For via `strings.Cut`, with NO `TrimSpace` (`realip.go:42-51`). Covered by REQ-002.
- **C-RIP-2** — `realIP` returns `""` (leaving `RemoteAddr` unchanged) when `net.ParseIP` fails, silently (`realip.go:52-55`, `realip.go:31-40`). Covered by REQ-002.

### middleware/content_charset.go (2 contracts)

- **C-CHS-1** — `contentEncoding` chains `split(...,";")`, `split(...,"charset=")`, `split(...,";")` and `slices.Contains` against the lowered allow-set (`content_charset.go:29-34`). Covered by REQ-002.
- **C-CHS-2** — `split` trims whitespace on both halves but does NOT strip quotes around a parameter value (`content_charset.go:37-45`). Covered by REQ-002.

### middleware/supress_notfound.go / page_route.go / path_rewrite.go (3 contracts)

- **C-SNF-1** — `SupressNotFound` calls `rctx.Routes.Match(rctx, r.Method, r.URL.Path)` reading the raw URL and passing the LIVE context (`supress_notfound.go:18-19`). Covered by REQ-001.
- **C-PGR-1** — `PageRoute` compares `r.URL.Path` (raw) against its configured absolute path with `strings.EqualFold` (`page_route.go:13`). Covered by REQ-001.
- **C-PRW-1** — `PathRewrite` rewrites and writes back `r.URL.Path` only, never `rctx.RoutePath` (`path_rewrite.go:11-12`). Covered by REQ-001.

### middleware/strip.go / get_head.go / url_format.go (3 contracts — the correct cohort)

- **C-STR-1** — `StripSlashes` reads `rctx.RoutePath` first and writes it back (`strip.go:17-29`). Reference behavior for REQ-001.
- **C-GHD-1** — `GetHead` reads `rctx.RoutePath`, falling back to `RawPath`/`Path` only when empty (`get_head.go:13-21`). Reference behavior for REQ-001.
- **C-URF-1** — `URLFormat` updates `rctx.RoutePath` after extracting the format suffix (`url_format.go:54-67`). Reference behavior for REQ-001.
