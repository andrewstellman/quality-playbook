# Harness lineage

`qpb_harness_tick.py`, `harness_ticker.py`, `harness_heartbeat.py`, and
`harness_demo_worker.py` are QPB's vendored copy of the **arunner** harness
generic core (formerly *wakecycle*; renamed to *arunner* at v0.1.0).
Canonical upstream: https://github.com/andrewstellman/arunner
(extracted from QPB 2026-06-12). These vendored scripts keep their QPB names; a drift
test pinned to an upstream release is a deferred release-time item.
