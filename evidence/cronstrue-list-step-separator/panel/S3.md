## Side-effect rule
Behaviour changes only for lists with a plain first member and a later step member in day-of-month, month, day-of-week or year. Old output was visibly malformed ("AMonly", " , "), so anyone matching on it as a string is unlikely and would be matching a bug. Likelihood of harm: very low. Locale effect: vi and sw text changes beyond the comma (step phrase now present). Affected: vi/sw users with such lists, rare; the PR discloses it.
