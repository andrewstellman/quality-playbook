# About this folder

This is the record of one bug from a Quality Playbook batch run, copied as it was written during the run (the `panel/`, `rev0/` and other subfolders are the review rounds' working files). `STATUS.md` and the submission log at the end of `REVIEW.md` were updated after the run as the pull request progressed. The files the scripts and reviews cite as `../dup-search.sh`, `../dup-search.out` and `pr-ref-scan.md` sat one level up in the run and are copied here at the top level, so `submit-draft-pr.sh` would need its `../` paths changed to run again.
